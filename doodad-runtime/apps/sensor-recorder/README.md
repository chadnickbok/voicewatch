# Sensor Recorder

Deterministic interactive conformance package.

Screens:

- ready at 50 HZ with a bounded XYZ capture buffer
- recording with elapsed time, sample count, live axes, pause, and finish
- safely paused with committed sample and memory status
- completed session with checksum and export actions
- CSV-ready result with a deterministic filename

Every transition crosses the domain-scoped mocked sensor capability before
mounting the next bounded AppSpec.

The launched app is title-free and all five documents select the shared
`live_action_detail` pattern from structure alone. The square profile keeps the
live metric, supporting data, and two decisive controls visible together,
adapting Google's paged round-screen exercise hierarchy to 240×240 hardware.
