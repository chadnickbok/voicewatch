# Sleep + Smart Alarm

Deterministic, title-free Sleep conformance package for the square 240×240
profile.

The real Wasm flow mounts five renderer-neutral AppSpec states:

- last-night result with duration and sleep score
- quiet overnight tracking with smart-alarm status
- completed morning summary
- stage breakdown
- seven-night trend

Every transition crosses the domain-scoped mocked sleep capability before
mounting the next bounded AppSpec. The displayed numbers are fixtures, not
medical measurements or advice.

The design references and their provenance are preserved in
`reference/inspiration/sleep`. The app uses declarative Material components;
it does not embed those images.
