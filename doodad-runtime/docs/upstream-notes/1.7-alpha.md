# Wear Compose 1.7 tracking notes

Wear Compose 1.7 is pre-release and does not define Doodad v1 behavior.

As of the 2026-07-30 baseline audit, the public release channel reports
1.7.0-alpha07 while 1.6.2 remains stable. Interesting changes—including
one-handed gesture APIs, TransformingLazyColumn work, and component fixes—stay
in this tracking document until a stable release is deliberately adopted.

Upgrade procedure:

1. Pin a stable artifact and exact AndroidX commit.
2. Regenerate tokens and component inventory.
3. Render every Android and LVGL catalog story.
4. Review API, semantic, motion, and square-adaptation changes.
5. Run RGB565 goldens and both hardware performance lanes.
6. Record an ADR superseding ADR-001.
