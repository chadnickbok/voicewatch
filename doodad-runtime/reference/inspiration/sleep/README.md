The square oracle borrows the references' information hierarchy: one dominant
sleep metric, a score or stage signal immediately beneath it, and a compact
path into history. It does not reproduce round-watch geometry or Apple
artwork. Google's current Pixel Watch guidance documents sleep goals, stages,
and bedtime behavior, while Apple demonstrates the usefulness of a
high-emphasis score and a separate history view.
