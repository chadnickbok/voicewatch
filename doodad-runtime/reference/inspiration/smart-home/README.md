Google's current product guidance confirms that Wear OS Home supports favorite
devices, light brightness/color/temperature, supported-device lock/unlock, and
deeper controls:
[Google Home on Wear OS](https://support.google.com/googlehome/answer/12791523).

The Doodad oracle adopts the hierarchy—not the product branding or circular
geometry: favorite status first, a dominant state value, immediate device
actions, visible command rollback, and an explicit confirmation boundary for
unlocking a door.
