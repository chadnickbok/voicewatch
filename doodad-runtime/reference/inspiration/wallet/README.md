Google's Wear guidance also confirms that supported passes can be presented as
QR or barcodes from the watch and discusses offline availability and scanner
density: [Use Google Wallet on your smartwatch](https://support.google.com/wearos/answer/14260807?hl=en).

The Doodad square adaptation keeps the route, boarding time, gate, and seat
glanceable, then devotes a separate title-free screen to the code. The code is
an original demo fixture, not a copied airline credential.
